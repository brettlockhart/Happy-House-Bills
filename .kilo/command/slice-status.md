# Slice Status Command

Show the status of all slices in the development lifecycle.

## Usage
```
/slice-status
```

## Output
Shows a table with all slices across lifecycle folders:
- 01-draft (not started)
- 02-in-progress (active implementation)
- 03-ready-for-review (awaiting review)
- 04-implemented (shipped)

## Example
```
/slice-status
```
